# Voice-line audio

Empty by design. Drop MP3s here named after the `slug` values in
`src/data/voiceLines.ts` and each player activates automatically:

    deliver-hope.mp3
    become-an-idol.mp3
    greeting.mp3
    thats-unfair.mp3
    sweets.mp3
    lets-go.mp3

Until then each card shows a disabled button labelled "Audio file not installed".
See CREDITS.md in the project root for why no audio ships with this repository.
